# NBA Player Stats

## Description

A beginner-friendly Python project that allows users to search for NBA players and view their statistics.

## Features

* Search for an NBA player
* Select the season to view
* Display player statistics
* Display stats from multiple teams if a player was traded
* Show combined statistics
* Search for another player
* Exit the program when finished

## Technologies Used

* Python 3
* NBA API
* PyCharm
* GitHub

## What I Learned

* Working with APIs
* Using Python functions
* Handling user input
* Using loops
* Working with data
* Handling invalid input
* Organizing a Python project
